# 2D Platformer Game (Python & Pygame)

A multi-level 2D platformer built from scratch in Python using Pygame as my A-Level Computer Science coursework project. Developed and documented across the full software development lifecycle (analysis, design, iterative development, structured testing, and evaluation).

## Key Features
- **Modular Architecture:** Separated game logic into clean, maintainable modules (`player.py`, `enemy.py`, `level.py`, `HUD.py`, `leaderboard.py`, and menu states).
- **Gameplay Mechanics:** Custom physics and collision detection, enemy AI patrolling/interactions, collectible items, health/HUD tracking, and a persistent leaderboard system.
- **Input Validation & Stability:** Built-in boundary checks, state management (`mainMenu.py`, `pauseMenu.py`), and edge-case handling to prevent crashes during gameplay.

## Controls
- **Move Left / Right:** `A` / `D` 
- **Jump:** `Space`
- **Pause:** `Esc`

## How to start
- Run game.py
- Make sure pygame is installed
